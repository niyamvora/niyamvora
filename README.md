### 🚀 Featured projects

#### 🔐 Enigma — privacy-focused native chat app

A modern, native take on a Telegram-style messenger, built around two things most chat apps don't
have together:

- **Nearby** — discover people physically around you (within a radius, or across a city) and message them.
- **Private chat** — an opt-in tier that is **end-to-end encrypted** (MLS / RFC 9420), so only the two phones can read it.

<p>
  <img src="https://img.shields.io/badge/Swift-iOS-FA7343?style=flat-square&logo=swift&logoColor=white" />
  <img src="https://img.shields.io/badge/Kotlin-Android-7F52FF?style=flat-square&logo=kotlin&logoColor=white" />
  <img src="https://img.shields.io/badge/Rust-MLS%20core-000000?style=flat-square&logo=rust&logoColor=white" />
  <img src="https://img.shields.io/badge/Elixir-Phoenix-4B275F?style=flat-square&logo=elixir&logoColor=white" />
  <img src="https://img.shields.io/badge/PostgreSQL-realtime-4169E1?style=flat-square&logo=postgresql&logoColor=white" />
</p>

Native **Swift (iOS)** + **Kotlin (Android)** clients share a single security-critical **Rust** core
(end-to-end encryption via [OpenMLS](https://github.com/openmls/openmls), bridged with UniFFI), backed
by an **Elixir / Phoenix** realtime service on the BEAM with **PostgreSQL** and Phoenix Channels over
WebSocket. Phone-number login (OTP via Twilio Verify); for private chats the server only ever relays
opaque ciphertext.

> _Status: early development — backend, realtime delivery, phone login, and the encryption core are built and working; native apps in progress (Android first)._
